# Монитор контекста — `~/.claude/ctxmon/`

Монитор показывает, сколько контекста занято, и предлагает Никите сжать разговор сообщением в чат. Сессиям он ничего не указывает: не держит ход, не запрещает скиллы и не требует вопросов (Никита, 2026-11-05: «Пусть показывает контекст и просто в ЧАТ без AskUser высвечивает предложение сжать»). Прежнее удержание хода и вопрос через AskUserQuestion остановили две автономные сессии примерно на полтора часа.

После любого сжатия монитор будит сессию сам: она прочитывает файлы из передачи и продолжает работу без сообщения Никиты (Никита, 2026-11-06: «очевидно пробуждение должно работать и после автоматического и после ручного сжатия»). Без пробуждения после ручного `/compact` Claude Code ждёт сообщения человека, и сессия молчит.

Монитор не зависит от `/context` и `/usage`. Контекст он берёт из журнала разговора: после каждого ответа там записан `usage` (input + cache_read + cache_creation). Размер окна он берёт из строки состояния: Claude Code зовёт её после каждого ответа.

## Что делает

| когда | Никите в чат | сессии |
|:--|:--|:--|
| всегда | строка состояния «контекст 54 % · 540 тыс. из 1 млн», цвет — по порогу | — |
| 50, 75, 85, 90 % | «Контекст занят на N %… Можно сжать разговор: /compact.» | — |
| `/compact` | сжатие не останавливается ни при каких условиях | `PreCompact` собирает передачу и кладёт копию в `handoffs/` |
| после сжатия | путь к передаче | `SessionStart` (compact): `start` подкладывает передачу, `wake` в фоне будит сессию — после ручного и автоматического сжатия; текст пробуждения: прочитать файлы «Прочитать целиком» и продолжать с первого шага передачи. Ход не держится |

Сжимает разговор только Никита, по своему решению. Передачу по-прежнему может сделать сессия: `ctxHandoff.py --session <id>`, но только если он попросит.

Каждый порог срабатывает один раз за жизнь окна. После сжатия и после `/clear` пороги снова взведены. Порог, сработавший по завышенной оценке, снова взводится, когда контекст ниже него на 3 %. Картинка в ответе инструмента считается за 1,6 тыс. токенов, а не по длине base64. Если контекст перескочил через несколько порогов, приходит один сигнал о старшем. Агентам (`agent_id` во входе хука) монитор ничего не делает.

## Файлы

| файл | что |
|:--|:--|
| `ctxCore.py` | общее: состояние сессии в `state/`, чтение журнала, пороги, вид чисел и путей |
| `ctxStatus.py` | строка состояния; пишет размер окна в `state/<id>.status.json` |
| `ctxHooks.py` | хуки: `prompt`, `post`, `stop` — сообщение в чат; `start`, `precompact` — передача; `wake` — пробуждение после сжатия; `skill` ничего не делает |
| `ctxHandoff.py` | передача: `--session <id>` — новая, `--check <путь>` — заполнена ли |
| `handoff-template.md` | шаблон передачи с подсказками |
| `ctxSelftest.py` | самопроверка на подставленных журналах |
| `trial-settings.json` | пробная сессия с порогами 7, 8, 9, 10 % |
| `state/`, `handoffs/`, `pending.json`, `ctxmon.log` | состояние, копии передач, журнал ошибок; старше 14 дней — удаляются |

## Команды

```bash
PYTHONIOENCODING=utf-8 python ~/.claude/ctxmon/ctxSelftest.py          # после каждой правки монитора: «всё сходится»
claude --settings ~/.claude/ctxmon/trial-settings.json # пробная сессия, общие настройки не тронуты
```

**После правки монитора** — обновить его копию в шаблоне NewFullSpec, папка `.claude/ctxmon/`: оттуда монитор ставится на другие машины. Как — её `INSTALL.md`, раздел «Обновить копию».

**Включить на всей машине** — в `~/.claude/settings.json` те же `statusLine` и `hooks`, что в `trial-settings.json`, без `--marks 7,8,9,10`. Включение сразу задевает все живые сессии. **Выключить** — убрать оба раздела.

**Пробуждение после сжатия** держится на втором хуке `SessionStart` — с `"matcher": "compact"` и `"asyncRewake": true`, команда `ctxHooks.py wake`. Без `asyncRewake` хук выполняется вместе со стартом сессии, и разбудить её ему нечем. `matcher` можно и не ставить: на обычном старте `wake` сам ничего не делает. Проверить без сжатия: `echo '{"session_id":"probe","source":"compact"}' | PYTHONIOENCODING=utf-8 python ~/.claude/ctxmon/ctxHooks.py wake; echo $?` — текст пробуждения и код 2.

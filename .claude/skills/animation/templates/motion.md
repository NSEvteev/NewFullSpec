# Движение: {{название задачи}}

Зачем: как объекты задачи движутся при смене состояний — значения для html-макета и для кода, одни и те же. Пишет `/animation` (шаг 12), читают `/dev` и агент блока. Характер движения, кривые и длительности поверхности — [дизайн-система](../_shared/design/{{поверхность}}.md), раздел «Движение»; здесь — только их применение. Макеты — [mockups/](mockups/).

Поля перехода:
- **Действие** — чем пользователь переводит объект: кнопка, жест, событие системы.
- **Термин** — из словаря `animation-vocabulary`, рядом слова решающего, если он описывал эффект.
- **Таблица кадров** — строка на движущийся элемент, по порядку старта. Роль: ведущий, второстепенный, украшение, неподвижный. Старт — от начала перехода, мс. Кривая — имя переменной из дизайн-системы или пружина с параметрами. Связь — вместе, с наложением, по очереди, перенос родителем.
- **Не движется** — элемент и причина.
- **Ослабленное движение** — что остаётся при `prefers-reduced-motion: reduce`.
- **Инструмент** — в макете и в коде.

Строка, которую предложила сессия и решающий ещё не принял, — с пометкой `(не согласовано)`; без пометки — согласовано.

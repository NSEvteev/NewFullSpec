# /dev-block: варианты блока

Зачем: что особого в брифе и у основной сессии по роду блока. Кто читает: `/dev-block`, шаг 7.

| Блок | Что особого в брифе | Что особого у основной сессии |
|---|---|---|
| **Окружение** — образ, зависимости, compose | агенту можно собрать образ и одноразовый контейнер; поднимать сервисы — нельзя | пересоздать контейнер; версии и тома — вживую; поднялись версии пакетов — решить, закреплять ли |
| **Схема базы** | DDL проверить без базы — выводом SQL миграции вверх и вниз | сразу после коммита — пересоздать контейнер, иначе сервис лежит; версия, колонки, описания |
| **Методы** | порядок маршрутов (конкретные раньше шаблонных); каждый отказ из описания — тестом | описание API; вызовы успеха и отказов |
| **Удаление** | «Удалить» — по файлам и функциям, дальше по цепочке после поиска; «Не трогать» — что читают другие; DELETED / KEPT / OTHER_DEAD; поиск удалённых имён — в проверках | поиск сам; недостижимого — 0; живое: оставшееся работает, удалённое отвечает как в описании |
| **Два репо** | два брифа, агенты параллельно; общий код — сначала в одном | стык сам (шаг 15), затем тесты второго против нового первого |
| **Интерфейс** | проверки и падающие «до» тесты — числом и списком файлов (`PROJECT.md`); контейнер не пересобирать; тесты с подменённой геометрией не заменяют проверку мышью — бриф называет её заранее | снимки на ширинах из `PROJECT.md`; формулировки описания — по снимку; **проверка мышью** — если блок дал объект и сценарий, которые человек проходит в браузере: сама сессия ведёт настоящий браузер (Playwright) так, как это сделает человек, — наводит, нажимает, тянет и отпускает с несколькими движениями по пути, прокручивает, проходит клавиатурой, уходит со страницы всеми путями (ссылки шапки, выход, закрытие вкладки) и во время загрузки — на данных, похожих на живые (с картинками, длинными именами); после каждого действия — снимок и сверка с обещанным |
| **Проверка вживую** | агента нет | скрипты в `$S`, шаг 13 целиком; проверка, которой надо ждать, — не блок, а задача бэклога с `CHECK.md` |

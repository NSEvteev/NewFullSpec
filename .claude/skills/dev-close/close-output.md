# /dev-close: что значит ответ `map.py close`

Зачем: что делать с каждой строкой ответа. Кто читает: `/dev-close`, шаг 6, когда в ответе есть что править.

## Перенос

| Строка | Что значит | Что делать |
|---|---|---|
| отказ: у блока нет `Сделано:` | блок не закончен | назад к блоку |
| отказ: копия вне правок разошлась с «как есть» | «как есть» менялось после копии | `map.py sync <md>`, пересмотреть правки рядом, повторить |
| «без «Код:»» | раздел, который блок не закрыл | в список находок |

## Ссылки на код по диффу

Первый `close` сверяет каждую ссылку `Код:` вне блоков правок: её строка в коде до изменения (родитель squash-коммита PR с обложки) по диффу переходит в строку нынешнего кода. Сверяются только ссылки, стоящие тем же путём и номером, что до изменения: новые и нарочно переставленные проверяет живая проверка. Ссылки, где `Код:` стоит внутри блока правки, писал блок: их переносит `relocate.py` и проверяет живая проверка.

| Строка | Что значит | Что делать |
|---|---|---|
| `по диффу: <md> <раздел>: <путь>:<было> → :<стало>` | номер поправлен сам | ничего |
| `вручную по диффу: <путь>:<строка> — строку переписали, на её месте строки :<a>–<b>; было «…»; кандидаты …; где: …` | строка кода переписана | открыть эти строки и поставить ссылку на строку действия или поправить абзац, сразу во всех названных md |
| `вручную по диффу: <путь>:<строка> — по диффу :<N>, но там другой текст — «…»; было «…»; кандидаты …` | дифф сдвинул бы ссылку на строку с другим текстом: рядом вставили строки | выбрать строку действия из кандидатов по «было» и поставить её; наугад номер не берётся |
| `по диффу от <коммит>: поправлено N, вручную M, запомненный текст обновлён у K` | итог сверки | ничего: у подтверждённых ссылок запомненный текст обновлён сам |
| «коммит слияния PR с обложки не найден» | на обложке нет `PR: #N` или squash-коммита с `(#N)` нет в истории | вписать номер и повторить `close` |
| `по диффу: сверено прошлым close … не поправлено вручную N из M` | повторный `close`: номера он не трогает, только напоминает | цель — 0 из M. Выбрал «поправить абзац», а номер верный и остался прежним, — проверить глазами и не считать долгом |

Сверка по диффу идёт один раз, первым `close`, и пишет отметку `TOBE/.diffchecked`. Пройти её заново (на обложке был не тот `PR:`) — удалить отметку и повторить `close`. Код поправили после первого `close` — сдвиги переносит `relocate.py` по тексту, его зовёт тот же `close`.

## Живая проверка

Ошибки — строками «не сделано: живая проверка — …». Отдельно `live.py` не запускать.

| Сообщение | Что значит | Что делать |
|---|---|---|
| факты разошлись у соседа | у соседа сдвинулся compose или код | `extract.py <сосед>` сразу, без `--tests` |
| ссылки на код нет, строка изменилась | код удалён или по ссылке другое; или ссылку уже верно перенёс `relocate`, а «было» в ошибке — запомненный текст другой ссылки с тем же номером | md — в список находок: переписать абзац или найти новую строку; абзац верен — `map.py accept <путь:строка>`. Номер менять только по сверке с диффом, не по тексту ошибки |
| ошибки под `TOBE/…` | «как есть» уже содержит изменение, «как будет» не сходится | ничего: «как будет» не править, оно уходит на очистке |
| ошибки по путям соседнего репо после его свежего коммита | чужое изменение (`PROCESS.md`, раздел 9) | отделить от своих; одним вопросом решающему — переписать сейчас или на старте следующего изменения |

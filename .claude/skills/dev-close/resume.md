# /dev-close: где остановились

Зачем: новая сессия после перерыва узнаёт, с какого шага `SKILL.md` продолжать. Кто читает: `/dev-close`, шаг 1. Команды — из корня репо; все они только читают, кроме `map.py close`, а его повтор безопасен: перенесённое он пропускает.

| Признак | Как посмотреть | Значит |
|---|---|---|
| факты задетых сервисов сняты после merge | дата `extracted_at` в `architecture/ASIS/<сервис>/.facts.json` | перенос начат |
| «как будет» перенесено, ссылки тоже | `map.py apply` — «уже перенесено», строк `перенесу` нет; `relocate.py --dry-run` — перенесено 0 | шаг 6 сделан |
| находки поправлены | `map.py close` — сделано N из N | шаги 7–9 сделаны |
| «как будет» пусто | `where.py` — «Изменения нет» | шаг 11 сделан; итог N из N — в журнале или сообщении коммита |
| коммиты | `git log --oneline -3`; `git status -sb` | шаг 14 сделан |
| обложки нет, а в «как есть» `:::` или `[[c-…` | предупреждение `where.py` «закрытие не доделано» | прервано на очистке, или правки «как будет» попали в «как есть»: найти их (`grep -rn ':::\|\[\[c-' architecture/ASIS`), переписать по коду, затем шаги 13–15 |

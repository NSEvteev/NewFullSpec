# /dev-describe: задачи, тесты, удаляемый код, судьбы проблем

Зачем: что писать в `tasks.md` и на обложке. Кто читает: `/dev-describe`, шаг 9. Формат — `architecture/STANDARD.md`, 7.7.

## Тесты

`Набор:` — папка тестов из реестра или «проверка вживую»; `Вид:` — новое, меняется, уходит; `Тест:` — имя существующего теста у «меняется» и «уходит» (найти поиском; переименование — словами в тексте, новое имя впишет блок); у «уходит» — только имена, которых после блока в коде не будет: проверку, которую блок переносит в новый тест дословно, называет новый тест, иначе закрытие найдёт имя в коде и не сойдётся; `Проверяет:` — правки; текст — что проверяется, с числами и договором.
- Тесты, которые станут ложными, — `уходит` или `меняется` с причиной; искать поиском старого поведения по тестам (миграция меняет умолчание — поиск старого умолчания). Новое событие потока, метод, поле ответа — поиск тестов, которые проверяют порядок событий, полный набор методов или путей, список модулей и точный ответ (`/health`).
- Данные теста — в тех разных состояниях, что бывают вживую: тест, где всё одинаково, не видит края.
- Переход старого значения в новое (роль, формат пропуска, формат файла) — своей правкой с тестом.
- Косметика (цвета, отступы, заголовки) — «проверка вживую» со снимком экрана, без юнит-тестов «у элемента есть класс».
- Новому механизму — самопроверка на игрушечных данных до настоящих.

## Задачи

`### <задача> {#k-<short>-<смысл>}`: путь и что сделать в коде — имена, значения, поведение в краях; `Правки:` — каждая правка файлов сервиса ровно в одной задаче; `Тесты:` — хотя бы один или текст, почему теста нет; `После:`. Первыми — задачи без зависимостей, дающие основу.

## Удаляемый код: выключенное = удалённое

У каждого «уходит» и «выключается» в коде — поле `Удаляется:` задачи: файлы целиком и имена, которые уходят в этом же изменении; в обратных кавычках только удаляемое. «Уходит» только в md — без него. Проверка сверяет его с кодом: до блока всё есть, после — ничего. Как найти: ссылки `Код:` уходящего, поиск вызовов и импортов, что станет недостижимым; удаляется файл — его импорты без других вызовов. Плюс тест «ушло». «Код остаётся до этапа N» — только словом решающего.

## Судьбы проблем и последствия

На обложке, `## Судьбы проблем`: каждой высокой проблеме задетых сервисов — закрывает `[[c-…]]`, остаётся (почему; где ещё проявится) или новая. Средние и низкие — если изменение их закрывает. Проблема, которая лишь указывает на чужую, — тоже судьба. «Остаётся» сверить с задачами: задача, меняющая код проблемы, — повод для «закрывает».

«Последствия для процессов» — строкой: что теперь увидит человек; по ним закрытие сверяет процессы.

## Документы

Поиск старых путей, команд, методов по живым документам репо и соседних (`CLAUDE.md`, `_backlog/`, README, скиллы, правила). Изменение меняет словарь системы (роли, вход, названия) — и инструменты карты (`project/settings.yaml`, `STANDARD.md`).

# Пакеты Python для инструментов карты: генератора страниц, проверок, поиска find.py, скрипта фактов.
#
# Зачем файл. Генератор собирает html из md, и проверка сравнивает каждую страницу со свежей сборкой
# байт в байт. Другая версия markdown может выдать другой html — тогда все страницы станут «устаревшими»
# без единой правки md. Поэтому версии закреплены точно, через ==.
#
# Как поставить (Python 3.12, из корня репо):
#     pip install -r architecture/tools/requirements.txt
# Так же ставит CI перед проверкой карты.
#
# Как менять версию. Только отдельным коммитом и вместе с полной сборкой: поднять версию здесь,
# собрать все страницы (build.py), закоммитить файл и пересобранные страницы вместе.
# Иначе проверка при коммите и CI покраснеют на страницах, которых никто не трогал.
#
# Новый пакет сюда — только если без него инструмент не написать: каждый пакет — ещё одна версия,
# которую надо держать одинаковой на всех машинах и в CI.

markdown==3.11

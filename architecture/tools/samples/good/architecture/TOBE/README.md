# Оплата с повтором

Платёжный шлюз может списать деньги и не успеть ответить — тогда заказ сейчас остаётся «новым» и закрывается как брошенный. orders будет повторять списание с ключом повтора, чтобы шлюз не списал дважды, а покупатель на странице заказов — ждать, пока оплата проверится.

Ветка: change/payment-retry
Требования: [_backlog/promt-payment-retry.md](../../_backlog/promt-payment-retry.md)

## Решения

- [[d-retry]] — повтор списания до трёх раз с ключом повтора, доводка фоном
- [[d-poll]] — страница ждёт оплату до 60 с и помнит заказ

## Не задеты

- Закрытие брошенных заказов при старте orders — работает как было: заказ, который фоновая доводка за час так и не довела, закрывается.

Интерфейс магазина. Страница заказов, на которой покупатель оформляет корзину. Сам он ничего не хранит, кроме корзины в браузере; заказы ведёт orders.

## Как устроен

React и Vite; запросы к сервисам идут через прокси Vite.
Код: `src/web/vite.config.ts:9`

## Связи

### → orders
Подпись: заказы
Адрес: [[VITE_ORDERS_URL]]
Вход: без входа
Ожидание: ждёт ответа, предела в коде нет; повторов нет
При отказе: показывает покупателю текст ошибки под кнопкой, корзина остаётся
Код: `src/web/src/api.ts:6` · `src/web/src/pages/OrdersPage.tsx:18`

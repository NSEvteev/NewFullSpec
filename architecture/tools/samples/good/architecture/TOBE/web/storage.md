## Память браузера: pending-order
Где: постоянно (localStorage)
Номер заказа, оплата которого ещё проверяется. Есть — страница при открытии показывает статус этого заказа и снова ждёт оплату, а «Оформить» недоступна, пока заказ не `paid` или `failed`; тогда номер стирается. Без этого после перезагрузки или через минуту ожидания покупатель оформил бы заказ ещё раз — с новым номером, то есть с новым ключом повтора, и шлюз списал бы дважды.
Почему: [[d-poll]]
:::
